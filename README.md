# Reverie (SillyTavern Extension)

> **ชื่อเดิม Chat Browser** — ตั้งแต่ v2.0.0 เปลี่ยนชื่อเป็น Reverie เพราะไม่ได้มีแค่รายการแชทแล้ว แต่เป็นคลังการ์ดทั้งหมดพร้อมตัวแก้ไขการ์ดสำหรับมือถือด้วย
> **ไม่มีอะไรหาย:** แชทที่ปักหมุด จำนวนข้อความใหม่ หน้าตาปุ่มลอยและไอคอน ใช้ต่อได้ทั้งหมด คำสั่ง `/chats` ยังใช้ได้ (เพิ่ม `/reverie` ให้ด้วย) ถ้าติดตั้งจากลิงก์เดิมไว้ กดอัปเดตตามปกติได้เลย

คลังการ์ดและแชทที่ทำมาให้ใช้บนมือถือก่อน: การ์ดทุกใบเป็นปกในแกลเลอรี แตะแล้วคุยต่อ เริ่มแชทใหม่ หรือแก้ไขการ์ดได้ทันที และแชททุกอันของทุกตัวละครและทุกกลุ่มอยู่ในรายการเดียว แตะแชทไหนก็ปิดแชทปัจจุบันแล้วเปิดแชทนั้นเลย ไม่ต้องเปิดการ์ดหรือเปิดกล่อง Manage chat files ก่อน

- **แกลเลอรี** ปกการ์ดของ**ทุก**ตัวละครและกลุ่ม รวมการ์ดที่เพิ่งนำเข้าและยังไม่มีแชท กรองตามแท็กและ ⭐ โปรด เรียงตามวันที่เพิ่มได้ แตะการ์ดเพื่อดูรายละเอียด คุยต่อ หรือ **เริ่มแชทใหม่**
- **แก้ไขการ์ด** ทุกช่องของการ์ด (คำอธิบาย ข้อความแรก ข้อความทักทายอื่น ตัวอย่างบทสนทนา ฯลฯ) ในหน้าจอเต็มที่พิมพ์ง่ายบนมือถือ ช่องพิมพ์ไม่โดนคีย์บอร์ดบัง มีร่างกันหาย

- เห็นว่าแชทไหน **ต่อเรื่องกัน** (ตอน 1 → 2 → 3) และมีความจำต่อกันจาก Memory Hub
- เห็นว่าแชทนี้ **ผูกกับ persona ไหน**
- บอก **จำนวนข้อความใหม่** ที่เข้ามาตั้งแต่เปิดแชทนั้นครั้งล่าสุดในเครื่องนี้ รวมถึงข้อความที่มาจากการซิงค์
- ตัวอย่างเนื้อหาเหลือแค่บทบรรยายกับบทพูด ไม่มีแท็ก แผงสเตตัส หรือ `<think>` มากวน
- ปักหมุด เปลี่ยนชื่อ ลบ ผูกตอนต่อเอง เลือกหลายแชทแล้วลบทีเดียว
- **ส่งออกไฟล์แชท** เป็น .jsonl (นำเข้ากลับ ST ได้) หรือ .txt อ่านง่าย รวมทั้งเรื่องหลายตอนเป็นไฟล์เดียวได้
- เลือกหลายการ์ดแล้วส่งต่อให้ **Bulk Manager** ลบ สำรอง หรือคัดลอกทีเดียว (ถ้าติดตั้งไว้)
- ปุ่ม **Sync** และ **Clean Sync** (ต้องใช้ [Chat Auto Backup](https://github.com/inathael-58/SillyTavern-Chat-AutoBackup) ที่เชื่อมต่อ Dropbox ไว้)

## ติดตั้ง

ใน SillyTavern เปิด **Extensions → Install extension** แล้ววาง URL นี้:

```
https://github.com/inathael-58/SillyTavern-Reverie
```

ลิงก์เดิม `https://github.com/inathael-58/SillyTavern-Chat-Browser` ยังใช้ได้ (GitHub ส่งต่อให้เอง) ใครติดตั้งไว้แล้วไม่ต้องลบติดตั้งใหม่ ชื่อในหน้า Extensions จะเปลี่ยนเป็น Reverie เองหลังอัปเดต

ถ้าจะใช้ Sync และ Clean Sync ให้อัปเดต Chat Auto Backup เป็น v2.5.0 ขึ้นไปด้วย

| ปรับอะไรได้ | |

| รูปทรง | วงกลม · มนเหลี่ยม · บับเบิลแชท · แคปซูล (มีข้อความ เช่น "แชท") · หัวใจ · ดอกไม้ · ดาว · ก้อนเมฆ · สติกเกอร์ (ไม่มีพื้น เหลือแค่ไอคอน/อีโมจิ/รูป) |

| ขนาด · ขนาดไอคอน · ความทึบ | มีช่องตัวเลขข้างแถบเลื่อน พิมพ์ค่าเองได้ (ขนาดและขนาดไอคอนเป็น px ความทึบเป็น %) ไว้ตั้งให้เท่ากับปุ่มลอยอื่น · ความทึบใช้ตอนไม่ได้แตะ แตะหรือชี้แล้วชัดเต็ม |
| สี | พื้นและไอคอน: **ปรับตามธีม** (ดึงจากแม่แบบสีของธีม ปรับให้อ่านง่ายบนพื้นปุ่มเสมอ เปลี่ยนธีมแล้วตามทันที) · **เลือกสีเอง** (ใช้สีนั้นทุกธีม) · หรือพื้นโปร่งใส |
| เคลื่อนไหว | นิ่ง · ลอยขึ้นลง · โยกเบา ๆ · เต้นตุบ ๆ · หมุนช้า ๆ · เรืองแสง · ดุ๊กดิ๊กเมื่อมีข้อความใหม่ |
| อื่น ๆ | ขอบ · เงา · ตัวเลขข้อความใหม่บนปุ่ม (มุมขวาบน ขนาดเดียวกับป้ายของ Lore Lens และ As you command จึงเรียงตรงกันใน Quick Dock) |

รูปที่เลือกจากเครื่องถูกย่อให้เล็กลง (GIF ไม่เกิน 500 KB ใช้ได้ทั้งไฟล์) และเก็บใน settings ของ ST จึงเห็นเหมือนกันทุกอุปกรณ์ที่ใช้ user เดียวกัน ถ้าเปิด "ลดการเคลื่อนไหว" ในระบบไว้ ปุ่มจะไม่ขยับ

## หน้าตา

ปุ่มสีบนหัวหน้าต่าง (🎨 / ☀️ / 🌙) แตะเพื่อสลับ **สีตามธีม → กลางวัน → กลางคืน** กลางวันและกลางคืนใช้พื้นสว่างหรือมืดของตัวเอง แต่ยังใช้สีเน้นของธีม จำค่าที่เลือกไว้

**เรียง** · ล่าสุด · ตัวละคร (จัดกลุ่มตามตัวละคร พับเก็บได้ทีละตัว) · ชื่อ ก–ฮ · ยาวสุด

**มุมมอง** (ปุ่มขวาบน)

| มุมมอง | เห็นอะไร |
|---|---|
| กะทัดรัด | ชื่อแชทบรรทัดเดียว จำนวนข้อความ และเวลา |
| ปกติ | ชื่อแชท จำนวนข้อความ ตัวละคร persona และข้อความล่าสุด 2 บรรทัด |
| ละเอียด | ข้อความล่าสุดได้ยาวขึ้น จำนวนข้อความ ขนาดไฟล์ จำนวนความจำของ Memory Hub สถานะ Dropbox และปุ่ม **ดูข้อความก่อนหน้า** (โหลดข้อความล่าสุด 6 ข้อความมาอ่าน) |
| แกลเลอรี | ปกการ์ดของทุกตัวละครและกลุ่ม ดูด้านล่าง |

ทุกมุมมอง (รวมรายการแชทในหน้าการ์ดของแกลเลอรี) บอกว่าแชทมีกี่ข้อความ: กะทัดรัด ปกติ และหน้าการ์ดแสดง 💬 ตามด้วยตัวเลขหน้าเวลา (บน PC ชี้ค้างที่ตัวเลขดูจำนวนรวมทั้งเรื่องของแชทที่ต่อเรื่องกัน) ส่วนละเอียดเขียนเต็มในบรรทัดล่าง

**ตัวกรอง** · มีข้อความใหม่ · ปักหมุด · แชทกลุ่ม · เฉพาะตัวละครที่เปิดอยู่ · persona (แตะแล้วเลือกจากรายการพร้อมรูปและจำนวนแชท) · รวมตอนต่อ (เปิด/ปิด)

**ค้นหา** จากชื่อแชท ชื่อตัวละคร ชื่อ persona และข้อความล่าสุด พิมพ์หลายคำได้

แชทที่เปิดอยู่มีแถบสีด้านซ้ายและป้าย "เปิดอยู่" แชทที่ปักหมุดอยู่บนสุดเสมอ (ยกเว้นตอนเรียงตามตัวละคร ซึ่งปักหมุดจะอยู่บนสุดของตัวละครนั้น)

บนมือถือ แถวค้นหา เรียง และตัวกรองจะพับเก็บตอนเลื่อนรายการลง ให้เห็นรายการเต็มจอ เลื่อนขึ้นนิดเดียวก็กลับมา

คีย์บอร์ด: `/` ไปช่องค้นหา · ↑ ↓ เลื่อน · Enter เปิด · Esc ปิด (Enter ในช่องค้นหาเปิดแชทแรกในรายการ)

## แกลเลอรี

ปุ่ม ⊞ ทางขวาสุดของปุ่มมุมมอง **ทุกตัวละครและทุกกลุ่ม** แสดงเป็นปกการ์ด รวมการ์ดที่เพิ่งนำเข้าและยังไม่เคยคุย (บนปกเขียนว่า "ยังไม่มีแชท") กลุ่มที่ไม่มีรูปของตัวเองใช้รูปสมาชิกต่อกัน บนปกบอกชื่อ จำนวนแชท เวลาล่าสุด ⭐ ตัวละครโปรด 📌 มีแชทที่ปักหมุด และ `+n` ข้อความใหม่ การ์ดที่เปิดอยู่มีขอบสีเน้น หัวหน้าต่างเปลี่ยนเป็น "การ์ด" พร้อมจำนวนการ์ด

- **ขนาดปก** ปุ่มเหนือตาราง: **ภาพใหญ่** (มือถือ 2 คอลัมน์ มีชื่อ จำนวนแชท และเวลาล่าสุด) หรือ **กะทัดรัด** (มือถือ 4 คอลัมน์ iPad/PC 6 คอลัมน์ เหลือแค่ชื่อกับตัวเลขข้อความใหม่ ไว้ไถดูไว ๆ ตอนมีบอทเยอะ) จำค่าที่เลือกไว้ สลับแล้วการ์ดที่อยู่บนสุดยังอยู่ตรงนั้น
- **จอใหญ่** หน้าต่างกว้างขึ้นเฉพาะตอนเปิดแกลเลอรี (ถึง 1320px) PC จอ 1080p ได้ 6 คอลัมน์ (ภาพใหญ่) หรือ 10 คอลัมน์ (กะทัดรัด) หน้าการ์ดยังเก็บข้อความกับรายการแชทไว้กลางจอ อ่านง่าย
- **เรียง** ล่าสุด (การ์ดที่ยังไม่มีแชทนับจากวันที่เพิ่ม) · **เพิ่มล่าสุด** (การ์ดที่นำเข้าหรือสร้างล่าสุดอยู่บนสุด) · ชื่อ · ยาวสุด (ข้อความรวมทุกแชท) ในรายการแชทยังมี "ตัวละคร" ตามเดิม
- **⭐ โปรด** แสดงเฉพาะตัวละครและกลุ่มที่ติดดาวไว้ใน ST
- **แท็ก** แตะชิป 🏷 แท็ก เลือกได้หลายแท็ก (มีจำนวนการ์ดของแต่ละแท็ก และช่องหาแท็กเมื่อมีเยอะ) แสดงเฉพาะการ์ดที่มี**ทุก**แท็กที่เลือก แตะ ✕ บนชิปเพื่อล้าง แท็กมาจากแท็กของ ST (tag ที่ใช้จัดโฟลเดอร์/กรองใน ST) ถ้าการ์ดไม่มีแท็กใน ST จะใช้แท็กที่เขียนไว้ในการ์ด
- ตัวกรองโปรด แท็ก ขนาดปก และการเรียง **จำไว้** เปิดครั้งหน้ายังเหมือนเดิม (เก็บใน settings ของ ST ทุกเครื่องเห็นเหมือนกัน)
- **ค้นหา** จากชื่อการ์ด แท็ก ผู้สร้าง และทุกอย่างที่ค้นได้ในรายการแชท ตัวกรอง (มีข้อความใหม่ ปักหมุด กลุ่ม persona) ใช้ได้เหมือนเดิม
- **แตะการ์ด** เปิดหน้าการ์ด: รูปใหญ่ (แตะเพื่อดูเต็มจอ) ชื่อ ผู้สร้าง เวอร์ชัน (ถ้าการ์ดใส่เป็นลิงก์ จะแสดงเป็นปุ่มลิงก์สั้น ๆ แตะเพื่อเปิด) จำนวนแชทและข้อความ แท็ก (แตะแท็กเพื่อค้นหาการ์ดที่มีแท็กเดียวกัน) **Creator's note** แบบย่อ มีปุ่ม **อ่านต่อ** ถ้ายาว และรายการแชททั้งหมดของการ์ดนี้ (ใช้ได้ทุกอย่างเหมือนรายการปกติ: ⋯ ตอนต่อ ปักหมุด ส่งออก)
- **ปุ่มบนหน้าการ์ด**
  - **คุยต่อแชทล่าสุด** เปิดแชทล่าสุดของการ์ดนี้
  - **เริ่มแชทใหม่** เลือกตัวละคร (หรือกลุ่ม) แล้วเริ่มแชทใหม่แบบเดียวกับ Start new chat ของ ST (ข้อความแรกและข้อความทักทายอื่นมาครบ) การ์ดที่ยังไม่มีแชทมีแค่ปุ่มนี้ แตะแล้ว ST เปิดแชทแรกให้เลย
  - **แก้ไขการ์ด** (เฉพาะตัวละคร) ดูหัวข้อถัดไป
  - **อัปเดตจากไฟล์** (เฉพาะตัวละคร เมื่อติดตั้ง Card Updater) ดูหัวข้อ “อัปเดตการ์ดจากไฟล์ → Card Updater”
- **การ์ดถัดไป / ก่อนหน้า** ปัดซ้ายขวาบนหน้าการ์ด ปุ่ม ‹ › ด้านบน หรือปุ่มลูกศรซ้ายขวาบนคีย์บอร์ด **‹ การ์ดทั้งหมด** หรือ Esc กลับไปที่เดิมในตาราง

รูปปกโหลดตอนเลื่อนใกล้ถึง (ระหว่างนั้นแสดงรูปย่อแบบเบลอไว้ก่อน) ทีละไม่กี่รูป ย่อให้พอดีช่องแล้วปล่อยรูปเต็ม และปล่อยรูปที่เลื่อนผ่านไปไกลแล้ว แกลเลอรียาว ๆ จึงไม่กินแรมจนแอปเด้ง (แอปที่ใช้ WebView อย่าง Tauri หรือแอปบนมือถือรับรูปการ์ดเต็มขนาดพร้อมกันหลายสิบรูปไม่ไหว)

### เลือกหลายการ์ด → Bulk Manager

ถ้าติดตั้ง [Bulk Manager](https://github.com/inathael-58/SillyTavern-Bulk-Manager) ไว้ ในแกลเลอรีจะมีปุ่ม ☑ ด้านบน (หรือกดค้างที่การ์ดบนมือถือ) แตะการ์ดเพื่อเลือก แล้วกด **ลบ** · **สำรอง** · **คัดลอก** ที่แถบด้านล่าง Reverie จะปิดแล้วเปิด Bulk Manager ที่แท็บตัวละครพร้อมการ์ดที่เลือกไว้ให้ ไปทำต่อในนั้น

- เลือกได้เฉพาะตัวละคร (กลุ่มยังไม่รองรับใน Bulk Manager)
- Bulk Manager รุ่นเก่าที่ยังไม่รับรายการจาก Reverie: จะเปิดด้วยคำสั่ง `/bulk` แทน และบอกว่าต้องเลือกการ์ดใหม่ในแผงนั้น อัปเดต Bulk Manager แล้วจะส่งต่อให้เอง
- ไม่ได้ติดตั้ง Bulk Manager: ปุ่มเลือกการ์ดจะไม่แสดง (ปุ่ม ☑ บนหน้าการ์ดยังเลือกหลายแชทได้ตามเดิม)

### อัปเดตการ์ดจากไฟล์ → Card Updater

ถ้าติดตั้ง [Card Updater](https://github.com/inathael-58/SillyTavern-CardUpdater) **1.6.0 ขึ้นไป** หน้าการ์ดของตัวละครจะมีปุ่ม **⬆ อัปเดตจากไฟล์** แตะแล้วหน้าเลือกไฟล์เปิดทันที (ใช้ได้บน iPhone) เลือกการ์ดใหม่ lorebook หรือ regex แล้ว Card Updater จะอัปเดต**ตัวละครของหน้านี้** เหมือนกดปุ่ม ⬆ ไฟล์ ในแผงตัวละคร (หน้าต่างก่อนอัปเดต หน้าสรุป ปุ่มย้อนกลับ)

- ไม่ต้องเปิดตัวละครนั้นก่อน และแชทที่เปิดอยู่ยังเป็นแชทเดิม
- Reverie ยังเปิดอยู่ที่หน้าการ์ดนี้ อัปเดตเสร็จแล้วโหลดข้อมูลใหม่ให้เอง
- ไม่ได้ติดตั้ง Card Updater หรือเป็นรุ่นเก่ากว่า 1.6.0: ปุ่มนี้จะไม่แสดง
- บน iPhone ให้เลือกการ์ดจากแอป Files ไม่ใช่คลังรูปภาพ (Photos ลบข้อมูลการ์ดในรูปทิ้ง)

## แก้ไขการ์ด

หน้าการ์ด → **แก้ไขการ์ด** เปิดตัวแก้ไขเต็มจอ ทำมาแทนช่องแก้ตัวละครของ ST ที่พิมพ์ยากมากบนมือถือ

**หน้ารายการช่อง** ทุกช่องเป็นแถวที่แตะได้ เห็นตัวอย่างสั้น ๆ จำนวนตัวอักษรและโทเคนโดยประมาณ (นับด้วย tokenizer ที่ ST ใช้อยู่)

| กลุ่ม | ช่อง |
|---|---|
| หลัก | ชื่อ · คำอธิบาย (Description) · บุคลิก (Personality) · ฉาก (Scenario) · ข้อความแรก (First message) · **ข้อความทักทายอื่น** (Alternate greetings) · ตัวอย่างบทสนทนา (Example dialogue) · Creator's note |
| ขั้นสูง (พับไว้) | System prompt · Post-history instructions · Character's note (ข้อความ ความลึก และส่งในนาม system/user/assistant) · ผู้สร้าง · เวอร์ชัน · แท็กในการ์ด |

**แตะช่อง** เปิดหน้าพิมพ์เต็มจอ

- ช่องพิมพ์ใหญ่เต็มพื้นที่ที่มองเห็น หน้าต่างย่อตามคีย์บอร์ดบนจอ แถบล่างกับช่องพิมพ์จึงอยู่เหนือคีย์บอร์ดเสมอ ตัวอักษร 16px Safari ไม่ซูมเข้าเอง
- ปุ่ม `{{char}}` `{{user}}` แทรกตรงเคอร์เซอร์ แตะแล้วคีย์บอร์ดไม่หุบ
- ปุ่ม ↺ **ย้อนการแก้ทั้งหมด**ในช่องนี้กลับเป็นข้อความตอนเปิด แตะอีกครั้ง (↻) เอากลับมา
- **เสร็จ** เก็บการแก้ไว้ในตัวแก้ไข (ยังไม่เขียนลงการ์ด) ✕ ถ้าแก้ไปแล้วจะถามก่อนว่าทิ้งหรือเก็บไว้
- ชื่อ ผู้สร้าง เวอร์ชัน เป็นช่องบรรทัดเดียว กด Enter = เสร็จ

**ข้อความทักทายอื่น** เป็นรายการ: แตะเพื่อแก้ ปุ่ม ↑ ↓ เรียงลำดับ 🗑 ลบ (ถามก่อนถ้ามีข้อความ) **เพิ่มข้อความทักทาย** และปุ่ม 👁 **ลองปัด** ดูข้อความแรกกับข้อความทักทายอื่นทีละอันแบบปัดซ้ายขวาเหมือนตอนเริ่มแชท (แทน `{{char}}` `{{user}}` ให้ด้วย) มีปุ่ม **ตั้งเป็นข้อความแรก** สลับข้อความที่ดูอยู่กับข้อความแรก

**แท็กในการ์ด** แก้เป็นชิป พิมพ์แล้วกด เพิ่ม (คั่นหลายแท็กด้วย `,`) แตะ ✕ เพื่อลบ เป็นแท็กที่เขียนในไฟล์การ์ด คนละชุดกับแท็กของ ST ที่ใช้กรองในแกลเลอรี

**บันทึก** ปุ่มขวาบนบอกว่าแก้ไปกี่ช่อง (ช่องที่แก้มีจุดสี) กดแล้วเขียนเฉพาะช่องที่เปลี่ยนลงการ์ด ทั้งแบบ v1 และ v2 เหมือนที่ ST เขียน ส่วนอื่นของการ์ด (lorebook ในการ์ด regex ของการ์ด ส่วนเสริมอื่น ๆ) ไม่ถูกแตะ แล้ว ST อัปเดตข้อมูลตัวละครในหน่วยความจำทันที ถ้าการ์ดนี้เปิดอยู่ในแผงตัวละครของ ST ช่องในแผงนั้นจะถูกเติมค่าใหม่ด้วย ST จึงไม่บันทึกค่าเก่าทับตอนบันทึกอัตโนมัติหรือตอนเริ่มแชทใหม่

**เปลี่ยนรูปการ์ด** แตะรูปบนหัวตัวแก้ไข (มีไอคอนกล้อง) หรือปุ่ม **เปลี่ยนรูปการ์ด** แล้วเลือกรูป (บน iPhone เลือกจากคลังรูปภาพหรือแอป Files ก็ได้)

- จัดกรอบ 2:3 เอง: ลากเพื่อเลื่อน ซูมด้วยสองนิ้ว แถบซูม หรือล้อเมาส์ แล้วกด **ใช้รูปนี้**
- ได้รูป 512×768 เท่ากับที่ ST ครอปให้ ถ้าตั้ง *Never resize avatars* ใน ST ไว้ จะได้ตามขนาดที่ครอป (ยาวสุด 2048px)
- เบราว์เซอร์แปลงรูปเป็น PNG ให้เอง ใช้ได้ทุกแบบที่เปิดดูได้ (JPEG, PNG, WebP, รูปจาก iPhone) และหมุนตามที่ถ่ายมาแล้ว (ภาพเคลื่อนไหวจะเหลือเฟรมเดียว)
- **เขียนลงการ์ดทันที** ไม่ต้องกดบันทึก ข้อมูลการ์ดไม่เปลี่ยน มีแค่รูป ใช้ endpoint เดียวกับปุ่มเปลี่ยนรูปของ ST
- **เห็นรูปใหม่ทันทีทุกที่** ST ใช้ URL เดิมกับรูปใหม่ เบราว์เซอร์ (โดยเฉพาะ Safari บน iPhone) เลยแสดงรูปเก่าที่จำไว้ Reverie จึงโหลดรูปใหม่เข้าแคชของเบราว์เซอร์ และเปลี่ยน URL ของทุกรูปของการ์ดนี้บนหน้า ทั้งใน Reverie ใน ST (รายชื่อตัวละคร แชท แผงตัวละคร) และในส่วนเสริมอื่น รวมถึงรูปที่ ST วาดใหม่ทีหลังจนกว่าจะรีโหลดหน้า
- ปุ่ม **ย้อนรูปเดิม** ใช้ได้จนกว่าจะปิดตัวแก้ไข
- เครื่องอื่นที่เปิด ST ค้างไว้อาจยังเห็นรูปเก่าจนกว่าจะรีโหลดหน้า

**กันหาย**

- ทุกตัวอักษรที่พิมพ์เก็บเป็น**ร่าง**ในเครื่องนี้ด้วย (ทั้งช่องที่กดเสร็จแล้วและช่องที่กำลังพิมพ์) Safari รีโหลดหน้า แอปถูกปิด หรือแบตหมด เปิดตัวแก้ไขการ์ดนั้นอีกครั้งจะมีแถบ **มีร่างที่ยังไม่ได้บันทึก** กด **กู้คืน** หรือ **ทิ้ง**
- กด ‹ กลับ (หรือ Esc) ตอนยังไม่ได้บันทึก จะถาม: **แก้ต่อ** · **ออกโดยไม่บันทึก** (ร่างยังเก็บไว้) · **บันทึกแล้วออก**
- บันทึกไม่สำเร็จ (เน็ตหลุด เซิร์ฟเวอร์ปิด) การแก้ยังอยู่ในตัวแก้ไขและในร่าง กดบันทึกใหม่ได้

เปลี่ยน**ชื่อ**ที่นี่เปลี่ยนแค่ชื่อที่แสดง ไฟล์การ์ด (`.png`) และโฟลเดอร์แชทยังใช้ชื่อเดิม แชทเดิมไม่หาย ถ้าอยากให้ชื่อไฟล์เปลี่ยนตามด้วยให้ใช้ปุ่มเปลี่ยนชื่อในแผงตัวละครของ ST

## ส่งออกไฟล์แชท

กด ⋯ ที่แชท → **ส่งออกไฟล์แชท…**

| แบบ | |
|---|---|
| ไฟล์แชท .jsonl | ไฟล์ต้นฉบับของ ST ครบทุกอย่าง (swipe, metadata, ความจำ) นำเข้ากลับได้ที่ Manage chat files → Import |
| ข้อความอ่านง่าย .txt | ชื่อ เวลา และข้อความทีละข้อความ เลือกได้ว่าจะเหลือแค่บทบรรยายกับบทพูด (ตัด `<think>` แผงสเตตัส HTML ออก) หรือเก็บข้อความดิบ |
| ทั้งเรื่อง .txt | แชทที่ต่อเรื่องกันหลายตอน รวมทุกตอนเป็นไฟล์เดียว เรียงจากตอนแรก |

บนมือถือมีปุ่ม **แชร์ / บันทึกลงไฟล์** (เปิดเมนูแชร์ของระบบ บันทึกลง Files หรือส่งต่อแอปอื่นได้) ถ้าเบราว์เซอร์รองรับ

## แชทที่ต่อเรื่องกัน

Reverie เรียกแต่ละแชทในเรื่องเดียวกันว่า **ตอน** (ตอน 1 → 2 → 3) รุ่นก่อน 2.2.0 เรียกว่า "ภาค" แต่เปลี่ยนเพราะ Memory Hub ใช้คำว่า **ภาค** กับอย่างอื่น คือกลุ่มความจำราว 10 ก้อน*ภายในแชทเดียว* · ตอน = แชทหนึ่งไฟล์ · ภาค (ของ Memory Hub) = ส่วนหนึ่งของความจำในแชทนั้น

| ที่มา | ทำอย่างไร |
|---|---|
| Memory Hub **เริ่มแชทใหม่ต่อเรื่อง** หรือ **นำเข้า → จากแชทอื่น** | ผูกให้อัตโนมัติ (อ่านจาก `chain` ใน metadata ของแชท) |
| ต่อเรื่องเองด้วยมือ | กด ⋯ ที่แชทตอนใหม่ → **ตั้งเป็นตอนต่อของ…** แล้วเลือกแชทก่อนหน้า ยกเลิกได้ด้วย **ยกเลิกการผูกตอนต่อ** |
| แตก branch ใน ST | แสดงป้าย "กิ่ง" (ไม่นับเป็นตอน) |

เปิด **รวมตอนต่อ** ไว้ แชทที่ต่อเรื่องกันจะรวมเป็นแถวเดียว แสดงตอนล่าสุด ส่วนตอนก่อน ๆ เปิดได้ในแตะเดียว ไม่ต้องเข้าตอนล่าสุดก่อน:

- ปุ่ม `ตอน 1 › ตอน 2 › ตอน 3` ใต้ตัวอย่างเนื้อหา (มุมมองกะทัดรัดเป็นปุ่มตัวเลข `1 2 3` ท้ายชื่อแชท ถ้ามีเกิน 3 ตอน จะมีปุ่ม `+n` เปิดดูที่เหลือ)
- แตะป้าย `ตอน 3/3` (หรือปุ่ม 🔗 ในมุมมองกะทัดรัด) เพื่อกางรายชื่อทุกตอน พร้อมชื่อแชท จำนวนข้อความ และเวลาล่าสุด แตะตอนไหนก็เปิดตอนนั้น
- เมนู ⋯ ของแถวนั้นมีรายการ **เปิดตอน n** ด้วย

ตัวเลข `+n` บนปุ่มคือข้อความใหม่ของตอนนั้น ถ้าแชทตอนก่อนถูกลบไปแล้ว เลขตอนยังนับตามเดิม (เช่น เหลือ ตอน 2 กับ ตอน 3)

## จำนวนข้อความใหม่

เครื่องนี้จำว่าตอนเปิดแชทครั้งล่าสุด แชทนั้นมีกี่ข้อความ ส่วนที่เพิ่มขึ้นแสดงเป็น `+n` จนกว่าจะเปิดแชทนั้น

- นับแยกในแต่ละเครื่อง/เบราว์เซอร์ คุยบนคอมแล้วมาเปิดในมือถือ มือถือจะเห็น `+n` ของแชทที่ซิงค์มา
- ครั้งแรกที่ติดตั้ง ทุกแชทถือว่าอ่านแล้ว
- แชทที่สร้างจากเครื่องอื่นหลังจากนั้นจะขึ้นจำนวนข้อความทั้งหมดเป็นข้อความใหม่
- ทำเครื่องหมายว่าอ่านแล้วได้จากเมนู ⋯ เลือกหลายแชท หรือ **ทุกแชทอ่านแล้ว** ในแผง Extensions

## ปักหมุด เปลี่ยนชื่อ ลบ

กด ⋯ (หรือคลิกขวาบนคอม) ที่แชท บนมือถือกดค้างที่แชทเพื่อเริ่มเลือกหลายแชท หรือกดปุ่ม ☑ ด้านบน

- **ปักหมุด** เก็บใน settings ของ ST บนเซิร์ฟเวอร์ ทุกอุปกรณ์ที่ใช้ user เดียวกันเห็นเหมือนกัน ครั้งแรกจะนำแชทที่ปักหมุดไว้ใน Recent Chats ของ ST มาด้วย
- **เปลี่ยนชื่อ** แชทอื่นที่อ้างถึงชื่อเดิม (ตอนต่อ กิ่ง ที่มาของความจำ) จะถูกแก้ตามให้ Chat Auto Backup ย้าย backup และไฟล์ใน Dropbox ไปชื่อใหม่ เครื่องอื่นเปลี่ยนตามตอนซิงค์ ใช้ได้กับการเปลี่ยนชื่อในหน้าต่างของ ST เองด้วย
- **ลบ** ถ้าลบแชทที่เปิดอยู่ จะสลับไปแชทล่าสุดอื่นของตัวละครนั้นก่อน (หรือเริ่มแชทใหม่ถ้าไม่มี) Chat Auto Backup ยังเก็บสำเนาไว้ในเครื่อง และถ้าเปิดซิงค์ไว้จะลบใน Dropbox และเครื่องอื่นตาม

## Sync และ Clean Sync

ใช้ Chat Auto Backup ที่เชื่อมต่อ Dropbox ไว้ ถ้าไม่ได้ติดตั้งหรือยังไม่ได้เชื่อม Dropbox ปุ่มทั้งสองจะไม่แสดง

- **Sync** — ซิงค์ตามปกติ เหมือนปุ่ม **ซิงค์ตอนนี้** ใน Chat Auto Backup เสร็จแล้วรายการโหลดใหม่ จุดสีบนปุ่มแปลว่ามีแชทรอเลือกฉบับ หรือซิงค์ครั้งล่าสุดไม่สำเร็จ
- **Clean Sync** — ใช้รายชื่อแชทในเครื่องนี้เป็นหลัก ทำให้ Dropbox และทุกเครื่องมีแชทเหมือนเครื่องนี้เป๊ะ
  1. ซิงค์ตามปกติก่อนหนึ่งรอบ (แชทที่อีกเครื่องเพิ่งสร้างจะถูกดึงมา ไม่ถูกลบ)
  2. แสดงรายการที่จะทำให้ดูก่อน: ลบออกจาก Dropbox (แชทที่ไม่มีในเครื่องนี้) · เก็บไว้ (แชทที่เครื่องอื่นลบไปแต่เครื่องนี้ยังมี) · ส่งขึ้น Dropbox (แชทที่ยังไม่เคยส่ง) เอาเครื่องหมายออกจากแชทที่อยากเก็บไว้ได้
  3. กดยืนยันแล้วจึงลบ แล้วบอกว่าลบอะไรไปบ้าง แต่ละอันมีปุ่ม **กู้คืน** ดูย้อนหลังได้ที่ **ประวัติการลบ** ในหน้า Clean Sync กู้ได้ประมาณ 30 วัน (ตามที่ Dropbox เก็บไฟล์ที่ลบไว้)
  4. เครื่องอื่นลบตามตอนซิงค์ครั้งถัดไป ถ้าแชทที่นั่นมีข้อความที่ยังไม่ได้ซิงค์ จะถามก่อน

  Clean Sync จัดการแค่ว่ามีแชทไหนบ้าง แชทที่แก้ทั้งสองฝั่งยังต้องเลือกฉบับเอง และไม่แตะ preset การ์ด lorebook persona Quick Reply หรือ regex

## ข้อจำกัด

- ตัวแก้ไขการ์ดแก้ได้เฉพาะข้อความในการ์ด ยังเปลี่ยนรูป แก้ lorebook ในการ์ด หรือแท็กของ ST ไม่ได้ (ใช้แผงตัวละครของ ST)

- โหลดรายชื่อแชทด้วย `/api/chats/recent` ของ SillyTavern 1.13 ขึ้นไป (คำขอเดียวได้ทุกแชท) รุ่นเก่ากว่าจะถามทีละตัวละคร ช้ากว่า
- เซิร์ฟเวอร์ต้องอ่านไฟล์แชททุกไฟล์เพื่อนับข้อความ ถ้ามีแชทยาวมาก ๆ หลายร้อยอัน การโหลดใหม่อาจใช้เวลาสักครู่ ระหว่างนั้นรายการจากครั้งก่อนจะแสดงไปก่อน (ไอคอนหมุนข้างชื่อ)
- ตัวอย่างเนื้อหามาจากข้อความล่าสุดของแชท (อาจเป็นข้อความของเรา) ตัดแท็ก บล็อก HTML แผงสเตตัส ข้อมูลสถานะแบบ JSON ตาราง โค้ด ลิงก์รูป OOC และ macro ออกหมด ใช้เฉพาะ regex ของ ST ที่ซ่อนข้อความ (แทนที่ด้วยค่าว่าง) ส่วน regex ที่แปลงเป็นแผงหรือหน้าจอเกมจะไม่ใช้ เพราะโค้ดของหน้าจอเหล่านั้นจะหลุดมาในตัวอย่าง
- persona แสดงได้เมื่อแชทล็อก persona ไว้ ถ้าไม่ได้ล็อกแต่ตัวละครผูก persona ไว้ จะแสดงแบบเส้นประ
- แชทที่ต่อเรื่องกันจะรู้อัตโนมัติเฉพาะที่สร้างผ่าน Memory Hub แชทเก่าที่ต่อเรื่องเองต้องผูกด้วยมือ
- จำนวนข้อความใหม่ใช้ได้แค่ในเบราว์เซอร์นี้ ล้างข้อมูลเว็บไซต์แล้วจะเริ่มนับใหม่

## เปลี่ยนชื่อ repo บน GitHub (สำหรับเจ้าของ repo)

ทำหลัง merge v2.0.0 แล้ว:

1. GitHub → repo `SillyTavern-Chat-Browser` → **Settings** → **General** → ช่อง **Repository name** พิมพ์ `SillyTavern-Reverie` → **Rename**
2. GitHub ส่งต่อลิงก์เดิมไปที่ใหม่ให้เอง (ทั้งหน้าเว็บและ `git clone` / `git pull`) เครื่องที่ติดตั้งจากลิงก์เดิมจึงกดอัปเดตใน ST ได้ตามปกติ ไม่ต้องติดตั้งใหม่
3. อย่าสร้าง repo ใหม่ชื่อ `SillyTavern-Chat-Browser` ในบัญชีเดิมอีก ไม่อย่างนั้นการส่งต่อจะหยุดทำงาน
4. ถ้ามีโคลนไว้ในเครื่อง เปลี่ยน remote ให้ตรง (ไม่บังคับ): `git remote set-url origin https://github.com/inathael-58/SillyTavern-Reverie.git`

โฟลเดอร์ที่ ST ติดตั้งไว้ในเครื่องยังชื่อ `SillyTavern-Chat-Browser` อยู่ ไม่เป็นไร โค้ดไม่ได้อ้างชื่อโฟลเดอร์ settings (`chat_browser`) ก็ยังเป็นชื่อเดิมเพื่อให้ของเดิมใช้ต่อได้
