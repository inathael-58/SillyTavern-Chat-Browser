# Chat Browser (SillyTavern Extension)

แชททุกอันของทุกตัวละครและทุกกลุ่มอยู่ในรายการเดียว แตะแชทไหนก็ปิดแชทปัจจุบันแล้วเปิดแชทนั้นเลย ไม่ต้องเปิดการ์ดหรือเปิดกล่อง Manage chat files ก่อน

- เห็นว่าแชทไหน **ต่อเรื่องกัน** (ภาค 1 → 2 → 3) และมีความจำต่อกันจาก Memory Hub
- เห็นว่าแชทนี้ **ผูกกับ persona ไหน**
- บอก **จำนวนข้อความใหม่** ที่เข้ามาตั้งแต่เปิดแชทนั้นครั้งล่าสุดในเครื่องนี้ รวมถึงข้อความที่มาจากการซิงค์
- ตัวอย่างเนื้อหาเหลือแค่บทบรรยายกับบทพูด ไม่มีแท็ก แผงสเตตัส หรือ `<think>` มากวน
- ปักหมุด เปลี่ยนชื่อ ลบ ผูกภาคต่อเอง เลือกหลายแชทแล้วลบทีเดียว
- ปุ่ม **Sync** และ **Clean Sync** (ต้องใช้ [Chat Auto Backup](https://github.com/inathael-58/SillyTavern-Chat-AutoBackup) ที่เชื่อมต่อ Dropbox ไว้)

## ติดตั้ง

ใน SillyTavern เปิด **Extensions → Install extension** แล้ววาง URL นี้:

```
https://github.com/inathael-58/SillyTavern-Chat-Browser
```

ถ้าจะใช้ Sync และ Clean Sync ให้อัปเดต Chat Auto Backup เป็น v2.5.0 ขึ้นไปด้วย

## เปิดใช้

| ทาง | |
|---|---|
| ปุ่มลอย 💬 | ลากไปวางตรงไหนก็ได้ (ดูดติดขอบจอ) หรือเก็บเข้า Quick Dock มีตัวเลขบอกว่ากี่แชทมีข้อความใหม่ ตอนคีย์บอร์ดบนจอเปิด ปุ่มจะขยับขึ้นมาอยู่ในส่วนที่มองเห็น |
| ไอคอน 💬 บนแถบด้านบน | แต่งได้ ดูด้านล่าง |
| เมนูไม้กายสิทธิ์ (Extensions) → Chat Browser | |
| คำสั่ง `/chats` | ใช้ทำปุ่มใน Quick Reply หรือ Quick Dock ได้ |

ปิดปุ่มลอยหรือไอคอนบนแถบด้านบนได้ในแผง Extensions → Chat Browser

### แต่งหน้าตาปุ่มลอย

แผง Extensions → Chat Browser → **หน้าตาปุ่มลอย** ปรับแล้วเห็นผลทันทีทั้งในกรอบตัวอย่างและปุ่มจริงบนจอ

| ปรับอะไรได้ | |
|---|---|
| สไตล์สำเร็จรูป | คลาสสิก · หัวใจ · ดาวเรือง · ดอกไม้ · บับเบิล · แคปซูล · ก้อนเมฆ · สติกเกอร์ — กดแล้วค่อยปรับต่อได้ |
| รูปทรง | วงกลม · มนเหลี่ยม · บับเบิลแชท · แคปซูล (มีข้อความ เช่น "แชท") · หัวใจ · ดอกไม้ · ดาว · ก้อนเมฆ · สติกเกอร์ (ไม่มีพื้น เหลือแค่ไอคอน/อีโมจิ/รูป) |
| หน้าปุ่ม | ไอคอน 18 แบบ · อีโมจิอะไรก็ได้ · รูปภาพ (เลือกจากเครื่อง หรือวางลิงก์ PNG พื้นใสหรือ GIF ได้) แบบเต็มกรอบหรือทั้งรูป |
| ขนาด · ขนาดไอคอน · ความทึบ | ความทึบใช้ตอนไม่ได้แตะ แตะหรือชี้แล้วชัดเต็ม |
| สี | พื้นและไอคอนใช้สีธีม เลือกสีเอง หรือพื้นโปร่งใส |
| เคลื่อนไหว | นิ่ง · ลอยขึ้นลง · โยกเบา ๆ · เต้นตุบ ๆ · หมุนช้า ๆ · เรืองแสง · ดุ๊กดิ๊กเมื่อมีข้อความใหม่ |
| อื่น ๆ | ขอบ · เงา · ตัวเลขข้อความใหม่บนปุ่ม |

รูปที่เลือกจากเครื่องถูกย่อให้เล็กลง (GIF ไม่เกิน 500 KB ใช้ได้ทั้งไฟล์) และเก็บใน settings ของ ST จึงเห็นเหมือนกันทุกอุปกรณ์ที่ใช้ user เดียวกัน ถ้าเปิด "ลดการเคลื่อนไหว" ในระบบไว้ ปุ่มจะไม่ขยับ

### แต่งไอคอนบนแถบด้านบน

แผง Extensions → Chat Browser → **หน้าตาไอคอนแถบด้านบน** เห็นผลทันทีที่ไอคอนจริง

| ปรับอะไรได้ | |
|---|---|
| ขนาด | 12–64px หรือ "ตามธีม" (ขนาดเดียวกับไอคอนอื่นของ ST) |
| หน้าไอคอน | ไอคอน 18 แบบ · อีโมจิ · รูปภาพ (ใช้ PNG พื้นใสให้เข้าชุดกับไอคอนของธีมได้) |
| สี · ความทึบ | สีธีมหรือเลือกเอง |
| ตัวเลขข้อความใหม่ | เปิด/ปิดได้ |

## หน้าตา

**เรียง** · ล่าสุด · ตัวละคร (จัดกลุ่มตามตัวละคร พับเก็บได้ทีละตัว) · ชื่อ ก–ฮ · ยาวสุด

**มุมมอง** (ปุ่มขวาบน)

| มุมมอง | เห็นอะไร |
|---|---|
| กะทัดรัด | ชื่อแชทบรรทัดเดียว |
| ปกติ | ชื่อแชท ตัวละคร persona และข้อความล่าสุด 2 บรรทัด |
| ละเอียด | ข้อความล่าสุดได้ยาวขึ้น จำนวนข้อความ ขนาดไฟล์ จำนวนความจำของ Memory Hub สถานะ Dropbox และปุ่ม **ดูข้อความก่อนหน้า** (โหลดข้อความล่าสุด 6 ข้อความมาอ่าน) |

**ตัวกรอง** · มีข้อความใหม่ · ปักหมุด · แชทกลุ่ม · เฉพาะตัวละครที่เปิดอยู่ · persona · รวมภาคต่อ (เปิด/ปิด)

**ค้นหา** จากชื่อแชท ชื่อตัวละคร ชื่อ persona และข้อความล่าสุด พิมพ์หลายคำได้

แชทที่เปิดอยู่มีแถบสีด้านซ้ายและป้าย "เปิดอยู่" แชทที่ปักหมุดอยู่บนสุดเสมอ (ยกเว้นตอนเรียงตามตัวละคร ซึ่งปักหมุดจะอยู่บนสุดของตัวละครนั้น)

คีย์บอร์ด: `/` ไปช่องค้นหา · ↑ ↓ เลื่อน · Enter เปิด · Esc ปิด (Enter ในช่องค้นหาเปิดแชทแรกในรายการ)

## แชทที่ต่อเรื่องกัน

| ที่มา | ทำอย่างไร |
|---|---|
| Memory Hub **เริ่มแชทใหม่ต่อเรื่อง** หรือ **นำเข้า → จากแชทอื่น** | ผูกให้อัตโนมัติ (อ่านจาก `chain` ใน metadata ของแชท) |
| ต่อเรื่องเองด้วยมือ | กด ⋯ ที่แชทภาคใหม่ → **ตั้งเป็นภาคต่อของ…** แล้วเลือกแชทก่อนหน้า ยกเลิกได้ด้วย **ยกเลิกการผูกภาคต่อ** |
| แตก branch ใน ST | แสดงป้าย "กิ่ง" (ไม่นับเป็นภาค) |

เปิด **รวมภาคต่อ** ไว้ แชทที่ต่อเรื่องกันจะรวมเป็นแถวเดียว แสดงภาคล่าสุด ส่วนภาคก่อน ๆ เปิดได้ในแตะเดียว ไม่ต้องเข้าภาคล่าสุดก่อน:

- ปุ่ม `ภาค 1 › ภาค 2 › ภาค 3` ใต้ตัวอย่างเนื้อหา (มุมมองกะทัดรัดเป็นปุ่มตัวเลข `1 2 3` ท้ายชื่อแชท ถ้ามีเกิน 3 ภาค จะมีปุ่ม `+n` เปิดดูที่เหลือ)
- แตะป้าย `ภาค 3/3` (หรือปุ่ม 🔗 ในมุมมองกะทัดรัด) เพื่อกางรายชื่อทุกภาค พร้อมชื่อแชท จำนวนข้อความ และเวลาล่าสุด แตะภาคไหนก็เปิดภาคนั้น
- เมนู ⋯ ของแถวนั้นมีรายการ **เปิดภาค n** ด้วย

ตัวเลข `+n` บนปุ่มคือข้อความใหม่ของภาคนั้น ถ้าแชทภาคก่อนถูกลบไปแล้ว เลขภาคยังนับตามเดิม (เช่น เหลือ ภาค 2 กับ ภาค 3)

## จำนวนข้อความใหม่

เครื่องนี้จำว่าตอนเปิดแชทครั้งล่าสุด แชทนั้นมีกี่ข้อความ ส่วนที่เพิ่มขึ้นแสดงเป็น `+n` จนกว่าจะเปิดแชทนั้น

- นับแยกในแต่ละเครื่อง/เบราว์เซอร์ คุยบนคอมแล้วมาเปิดในมือถือ มือถือจะเห็น `+n` ของแชทที่ซิงค์มา
- ครั้งแรกที่ติดตั้ง ทุกแชทถือว่าอ่านแล้ว
- แชทที่สร้างจากเครื่องอื่นหลังจากนั้นจะขึ้นจำนวนข้อความทั้งหมดเป็นข้อความใหม่
- ทำเครื่องหมายว่าอ่านแล้วได้จากเมนู ⋯ เลือกหลายแชท หรือ **ทุกแชทอ่านแล้ว** ในแผง Extensions

## ปักหมุด เปลี่ยนชื่อ ลบ

กด ⋯ (หรือคลิกขวาบนคอม) ที่แชท บนมือถือกดค้างที่แชทเพื่อเริ่มเลือกหลายแชท หรือกดปุ่ม ☑ ด้านบน

- **ปักหมุด** เก็บใน settings ของ ST บนเซิร์ฟเวอร์ ทุกอุปกรณ์ที่ใช้ user เดียวกันเห็นเหมือนกัน ครั้งแรกจะนำแชทที่ปักหมุดไว้ใน Recent Chats ของ ST มาด้วย
- **เปลี่ยนชื่อ** แชทอื่นที่อ้างถึงชื่อเดิม (ภาคต่อ กิ่ง ที่มาของความจำ) จะถูกแก้ตามให้ Chat Auto Backup ย้าย backup และไฟล์ใน Dropbox ไปชื่อใหม่ เครื่องอื่นเปลี่ยนตามตอนซิงค์ ใช้ได้กับการเปลี่ยนชื่อในหน้าต่างของ ST เองด้วย
- **ลบ** ถ้าลบแชทที่เปิดอยู่ จะสลับไปแชทล่าสุดอื่นของตัวละครนั้นก่อน (หรือเริ่มแชทใหม่ถ้าไม่มี) Chat Auto Backup ยังเก็บสำเนาไว้ในเครื่อง และถ้าเปิดซิงค์ไว้จะลบใน Dropbox และเครื่องอื่นตาม

## Sync และ Clean Sync

ใช้ Chat Auto Backup ที่เชื่อมต่อ Dropbox ไว้ ถ้าไม่ได้ติดตั้งหรือยังไม่ได้เชื่อม Dropbox ปุ่มทั้งสองจะไม่แสดง

- **Sync** — ซิงค์ตามปกติ เหมือนปุ่ม **ซิงค์ตอนนี้** ใน Chat Auto Backup เสร็จแล้วรายการโหลดใหม่ จุดสีบนปุ่มแปลว่ามีแชทรอเลือกฉบับ หรือซิงค์ครั้งล่าสุดไม่สำเร็จ
- **Clean Sync** — ใช้รายชื่อแชทในเครื่องนี้เป็นหลัก ทำให้ Dropbox และทุกเครื่องมีแชทเหมือนเครื่องนี้เป๊ะ
  1. ซิงค์ตามปกติก่อนหนึ่งรอบ (แชทที่อีกเครื่องเพิ่งสร้างจะถูกดึงมา ไม่ถูกลบ)
  2. แสดงรายการที่จะทำให้ดูก่อน: ลบออกจาก Dropbox (แชทที่ไม่มีในเครื่องนี้) · เก็บไว้ (แชทที่เครื่องอื่นลบไปแต่เครื่องนี้ยังมี) · ส่งขึ้น Dropbox (แชทที่ยังไม่เคยส่ง) เอาเครื่องหมายออกจากแชทที่อยากเก็บไว้ได้
  3. กดยืนยันแล้วจึงลบ แล้วบอกว่าลบอะไรไปบ้าง แต่ละอันมีปุ่ม **กู้คืน** ดูย้อนหลังได้ที่ **ประวัติการลบ** ในหน้า Clean Sync กู้ได้ประมาณ 30 วัน (ตามที่ Dropbox เก็บไฟล์ที่ลบไว้)
  4. เครื่องอื่นลบตามตอนซิงค์ครั้งถัดไป ถ้าแชทที่นั่นมีข้อความที่ยังไม่ได้ซิงค์ จะถามก่อน

  Clean Sync จัดการแค่ว่ามีแชทไหนบ้าง แชทที่แก้ทั้งสองฝั่งยังต้องเลือกฉบับเอง และไม่แตะ preset การ์ด lorebook persona Quick Reply หรือ regex

## ข้อจำกัด

- โหลดรายชื่อแชทด้วย `/api/chats/recent` ของ SillyTavern 1.13 ขึ้นไป (คำขอเดียวได้ทุกแชท) รุ่นเก่ากว่าจะถามทีละตัวละคร ช้ากว่า
- เซิร์ฟเวอร์ต้องอ่านไฟล์แชททุกไฟล์เพื่อนับข้อความ ถ้ามีแชทยาวมาก ๆ หลายร้อยอัน การโหลดใหม่อาจใช้เวลาสักครู่ ระหว่างนั้นรายการจากครั้งก่อนจะแสดงไปก่อน (ไอคอนหมุนข้างชื่อ)
- ตัวอย่างเนื้อหามาจากข้อความล่าสุดของแชท (อาจเป็นข้อความของเรา) ตัดแท็ก บล็อก HTML แผงสเตตัส ข้อมูลสถานะแบบ JSON ตาราง โค้ด ลิงก์รูป OOC และ macro ออกหมด ใช้เฉพาะ regex ของ ST ที่ซ่อนข้อความ (แทนที่ด้วยค่าว่าง) ส่วน regex ที่แปลงเป็นแผงหรือหน้าจอเกมจะไม่ใช้ เพราะโค้ดของหน้าจอเหล่านั้นจะหลุดมาในตัวอย่าง
- persona แสดงได้เมื่อแชทล็อก persona ไว้ ถ้าไม่ได้ล็อกแต่ตัวละครผูก persona ไว้ จะแสดงแบบเส้นประ
- แชทที่ต่อเรื่องกันจะรู้อัตโนมัติเฉพาะที่สร้างผ่าน Memory Hub แชทเก่าที่ต่อเรื่องเองต้องผูกด้วยมือ
- จำนวนข้อความใหม่ใช้ได้แค่ในเบราว์เซอร์นี้ ล้างข้อมูลเว็บไซต์แล้วจะเริ่มนับใหม่
